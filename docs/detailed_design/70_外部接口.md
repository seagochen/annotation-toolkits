# 外部接口

本平台只有一套 HTTP API（[`server.py`](../../backend/annotation_platform/server.py)），
对全部任务类型通用；本文档也是唯一允许写具体字段值和示例的地方（其余文档一律引用
回这里）。`TaskTypeModule.export()` 是 **Python 级能力，没有对应的 HTTP 端点**——
导出产物落盘后，通过下面的"文件"端点读取。

默认监听 `127.0.0.1:8000`，接口文档见 `http://127.0.0.1:8000/docs`（FastAPI 自动生成）。

## 端点一览

| 方法 & 路径 | 说明 |
|---|---|
| `GET /api/projects` | 列出全部项目 |
| `GET /api/projects/{id}` | 单个项目详情 |
| `GET /api/projects/{id}/queue` | 队列分页查询 |
| `POST /api/projects/{id}/annotations` | 提交一个 item 的标注结果 |
| `GET /api/projects/{id}/actions` | 列出支持的动作与历史任务 |
| `POST /api/projects/{id}/actions/{action}` | 启动一个后台动作 |
| `GET /api/projects/{id}/actions/jobs/{job_id}` | 查询后台任务状态 |
| `GET /api/projects/{id}/files/{path}` | 读取项目根目录下的文件 |

## 通用错误响应

所有错误响应体形状一致：

```json
{ "detail": { "code": "task_conflict", "message": "..." } }
```

`code` 的取值见 [`10_通用设计.md`](10_通用设计.md) §2。

## `GET /api/projects`

返回 `ProjectListItem[]`：

```json
[{ "id": "scene-detection", "name": "Scene Detection", "task_type": "detection", "root": "/abs/path", "status": "reviewing" }]
```

`status` 取值：`missing`（数据集目录不存在）、`empty`（无可标注文件）、`reviewing`
（有未完成 item）、`reviewed`（全部完成）；ReID 额外有 `needs_mining`。

## `GET /api/projects/{id}`

返回 `ProjectDetail`：在 `ProjectListItem` 基础上加 `summary`（任务自定义字典，
字段因任务类型而异，见下）。404 时 `code: project_not_found`。

## `GET /api/projects/{id}/queue`

查询参数：`offset`（默认 0）、`limit`（默认 60，1–200）、`status`、`q`、`kind`、
`split`（后两个仅 ReID 使用）。返回 `QueueResponse`：

```json
{ "total": 12, "offset": 0, "limit": 60, "items": [ /* 任务自定义字典数组，见下 */ ] }
```

## `POST /api/projects/{id}/annotations`

请求体 `AnnotationRequest`：`{ "item_id": "...", "result": { /* 任务自定义 */ } }`。
成功返回 `AnnotationResponse`：`{ "item": {...}, "status": { "state": "...", "details": {...} } }`。
409 = 与已保存结果冲突（`code: task_conflict`），422 = 校验失败。

## 各任务类型的 `result` / `item` / `summary` 形状

### classification

`summary`：`{ "mode": "single"|"multi", "labels": [...] }`。`queue().items[]` 每项：
`{ "item_id", "image_path", "labels": string[] }`。提交 `result`：

```json
{ "labels": ["outdoor"] }
```

约束：`labels` 必须全部在配置的 `labels` 内、不重复；`single` 模式恰好一个，
`multi` 模式至少一个；保存时按配置声明顺序重排。导出（Python，非 HTTP）：
`format=native|json`（原样返回 JSON 侧车）、`format=csv`（`item_id,image_path,labels`）。

### captioning

`summary`：`{}`（无任务专属字段）。`queue().items[]`：
`{ "item_id", "image_path", "caption": string }`。提交 `result`：

```json
{ "caption": "一只猫在窗边睡觉。" }
```

约束：`\r\n`/`\r` 归一化为 `\n`，首尾裁剪；裁剪后为空一律拒绝；长度上限 2000 字符
（裁剪后计数）。导出：`format=native|json`、`format=csv`
（`item_id,image_path,caption`）。

### detection

`summary`：`{ "categories": string[] }`。`queue().items[]`：
`{ "item_id", "image_path", "boxes": Box[] }`。提交 `result`（坐标为原图像素坐标，
左上角为 `(0,0)`）：

```json
{
  "image_size": { "width": 1920, "height": 1080 },
  "boxes": [{ "category": "person", "x": 120, "y": 80, "width": 60, "height": 140 }]
}
```

约束：`image_size` 的 `width`/`height` 必须是正整数，首次提交固定下来；`box` 越界
（超出 `image_size`）、宽高非正、`category` 不在配置内一律拒绝（HTTP 422），不做
静默裁剪；空 `boxes` 列表是合法提交（"确认没有目标"）。

导出（Python，非 HTTP）：`format=native|json`；`format=coco` 写出 `coco.json`
（`category_id` 按配置 `categories` 顺序从 1 编号，`image_id`/`annotation.id` 按
item/box 排序确定性生成，`image_size` 序列化为整数，`bbox`/`area` 为浮点数）：

```json
{
  "images": [{ "id": 1, "file_name": "a.jpg", "width": 1920, "height": 1080 }],
  "categories": [{ "id": 1, "name": "person" }, { "id": 2, "name": "vehicle" }],
  "annotations": [{ "id": 1, "image_id": 1, "category_id": 1, "bbox": [120.0, 80.0, 60.0, 140.0], "area": 8400.0, "iscrowd": 0 }]
}
```

### segmentation

`summary`：`{ "categories": string[] }`（像素值 `1..N` 对应第 `1..N` 个类别，`0` 恒为
背景）。`queue().items[]`：`{ "item_id", "image_path", "mask_path", "image_size" }`
（未标注时后两者为 `null`）。提交 `result`——**整图栅格替换**，不是增量笔画或多边形
顶点（前端的多边形/画笔都只是作画方式，见 [`20_标注平台后端.md`](20_标注平台后端.md) §5）：

```json
{ "image_size": { "width": 640, "height": 480 }, "pixels": "<base64，width*height 字节>" }
```

约束：`pixels` 解码后长度必须恰好等于 `width*height`；像素值不能超过配置的类别数；
幂等判定用像素 sha256；不一致的重复提交拒绝为 409。

导出（Python，非 HTTP）：`format=native`（`index.json` + 各 item 的掩膜 PNG 路径）；
`format=coco` 写出 `coco.json`，`segmentation` 字段是**掩膜文件路径引用**，不是
RLE/polygon 编码（"COCO 兼容"而非完整实现）：

```json
{
  "images": [{ "id": 1, "file_name": "a.jpg", "width": 640, "height": 480 }],
  "categories": [{ "id": 1, "name": "road" }, { "id": 2, "name": "building" }],
  "annotations": [{ "image_id": 1, "segmentation_mask": "<item_id>.png" }]
}
```

掩膜文件本身通过 `GET /api/projects/{id}/files/.annotations/segmentation/<item_id>.png`
读取，是一张真实的 8-bit 灰度 PNG。

### depth

`summary`：`{}`。`queue().items[]`：
`{ "item_id", "image_path", "baseline_path", "depth_path", "image_size" }`
（`baseline_path` 是该 item 对应的基线深度图相对路径，没有基线时为 `null`；
`depth_path`/`image_size` 未标注时为 `null`）。提交 `result`——同样是**整图栅格
替换**（画笔的"提高/降低"语义完全是前端交互，提交的是最终整图栅格）：

```json
{ "image_size": { "width": 640, "height": 480 }, "pixels": "<base64，0-255 灰度值>" }
```

约束同 segmentation（长度校验、像素 sha256 幂等），但没有类别数上限（任意 0–255
合法）。导出（Python，非 HTTP）：只支持 `format=native`（`index.json` + 各 item 的
编辑后深度图 PNG 路径）；深度图不是结构化标注，没有 COCO 等价物。

基线图与编辑结果都通过文件端点读取：

```bash
curl http://127.0.0.1:8000/api/projects/{id}/files/.depth-baseline/a.png
curl http://127.0.0.1:8000/api/projects/{id}/files/.annotations/depth/<item_id>.png
```

### reid

`summary`：见 `backend/README.md`（ReID 的 `Project.summary()`）。`queue().items[]`：
候选对字段（`candidate_id`、`person_id1`/`person_id2`、`gallery1`/`gallery2` 等）。
提交 `result`：

```json
{ "label": "same", "notes": "clear" }
```

`label` 取值 `same`/`different`/`unclear`；`notes` 可选。导出：只支持
`format=native`，返回当前 `pairs.csv`。ReID 额外暴露 `TaskActionModule` 六个后台
动作（`extract`/`mine`/`check`/`finalize`/`purge-domain`/`train`），通过
`POST /api/projects/{id}/actions/{action}` 启动、`GET .../actions/jobs/{job_id}`
轮询；各动作接受的 `options` 布尔开关见 `backend/README.md`。

## `GET /api/projects/{id}/files/{path}`

`path` 相对于该项目的 `root`（即任务配置里的 `dataset`）；`resolve()` 后校验必须
落在 `root` 内部，逃逸或不存在返回 404（`code: file_not_found`）。响应
`Content-Type` 由文件扩展名猜测（`mimetypes.guess_type`）。

## 示例：完整提交一次检测标注

```bash
ITEM=$(curl -s http://127.0.0.1:8000/api/projects/scene-detection/queue \
  | python3 -c "import json,sys;print(json.load(sys.stdin)['items'][0]['item_id'])")

curl -s -X POST http://127.0.0.1:8000/api/projects/scene-detection/annotations \
  -H 'Content-Type: application/json' \
  -d "{\"item_id\": \"$ITEM\", \"result\": {\"image_size\": {\"width\": 640, \"height\": 480}, \"boxes\": []}}"
```
