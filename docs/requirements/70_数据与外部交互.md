# 数据与外部交互需求

## FR-012 本地数据保存与导出

**依据与确认情况**：工程总览的本地存储定位与当前任务模块行为；参与者为数据准备者、标注者和数据消费者。完成标注后，数据消费者可通过 Python 任务导出能力取得受支持的产物，并在交付时保留图片引用和相关栅格。格式完整契约见[外部接口](../detailed_design/70_外部接口.md)；不支持的格式应被拒绝。

| 数据 | 来源与归属 | 使用及交付约束 |
|---|---|---|
| 项目注册表与标签配置 | 本地操作者 | 决定任务类型、数据目录、类别含义；改变类别顺序可能改变既有数据解释 |
| 图像与深度基线 | 本地数据集 | 标注读取源数据，深度结果另存；交付者维持相对路径关系 |
| 分类、描述、检测结果 | 对应任务模块 | 原生结果可重新加载；分类、描述另支持表格，检测另支持 COCO 兼容结果 |
| 分割、深度结果 | 对应任务模块 | 索引与 PNG 一起交付；分割的 COCO 兼容结果引用掩膜文件，并非标准 RLE/polygon |
| ReID 候选、人工判定与定版产物 | ReID 子系统 | 保留关系来源；原生导出提供关系数据，训练交接需要其余关联文件 |
| 动作历史与日志 | ReID 执行器 | 用于观察执行及重启后的失败追溯 |

当前没有通用 HTTP 导出端点或数据上传端点。数据保留期限、自动清理和删除审计没有已确认需求；本次不承诺新增能力。备份建议见[部署与演进](../overall_design/90_部署与演进.md)。

**验收**：[AC-012](90_验收标准.md#ac-012)。

## FR-013 外部参与方与失败可见性

**依据与确认情况**：当前接口、[流水线契约](../../backend/reid_annotation_tool/contract.py)和 [handoff.py](../../backend/reid_annotation_tool/handoff.py) 的既有行为。数据准备者提供路径可用、输出满足约定的流水线；训练消费者提供可执行的外部训练工程。普通图像标注不以外部模型服务可用为前提。

浏览器访问后端失败时显示错误；项目根目录外或不存在的文件不能通过文件接口读取。外部流水线或训练器失败时，后台动作记录失败与可用诊断，不报告已成功完成。平台没有对任意外部脚本提供自动重试、回滚或执行隔离的契约。

**验收**：[AC-013](90_验收标准.md#ac-013)。
