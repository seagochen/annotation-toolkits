## 2. 背景与目标

平台面向本地数据集，把不同标注任务纳入统一项目入口，并保留 ReID 从原始数据到训练交接的工作流程。产品参考 Label Studio 的项目和标注交互，自行实现轻量系统。

| 目标 | 可观察的成功标准 | 依据 |
|---|---|---|
| 统一标注入口 | 使用者从项目列表进入对应任务并保存结果 | 工程总览、FR-001～FR-007 |
| 保留本地数据控制 | 标注落在配置指定的本地数据集中，可重新加载和导出 | 工程总览、FR-012 |
| 人工掌握 ReID 身份真值 | 模型仅辅助排序，人工判定经检查后用于训练交接 | ReID 操作手册、FR-008～FR-010 |
| 降低任务扩展耦合 | 通用 API 不解释任务专属业务字段 | 详细设计、NFR-004 |

## 3. 范围与约束

纳入六种现有任务类型、文件读取、项目状态、Python 导出能力及 ReID 后台动作。项目通过本地配置登记，当前没有浏览器上传数据、创建项目向导、用户账户、审核员权限、多人任务分配或云存储能力。

图像描述是针对图片填写文本，不代表已支持独立文本数据的分类或序列标注。文本标注范围在原有文档中被列为未确定项，本次不扩展其产品承诺。性能、容量、可用性及备份恢复时限没有已有数值依据。

## 16. 向下一工程的移交

### 16.1 设计与验收

[总体设计](../overall_design/00_概述.md)分配系统职责；[详细设计](../detailed_design/00_概述.md)维护模块契约。验收按各 AC 准备独立临时数据集，包含正常、非法输入、重复提交和存储失败场景。现有测试文件是验证入口，本文不声明它们在本次文档任务中已执行通过。执行进度继续由项目 Issues 管理。

### 16.2 尚需业务依据的问题

| 问题 | 影响 | 所需信息 |
|---|---|---|
| 独立文本标注范围 | 新增任务类型与交互设计 | 数据单元、标签结构、输入输出格式 |
| 大图与大数据集规模 | 容量及性能验收 | 代表性样本、硬件、目标响应时间 |
| 修订已提交的图像标注 | 当前重复提交保护与编辑流程 | 是否需要修订，以及版本与历史保留规则 |
| 导出入口与下游兼容目标 | 是否新增 HTTP/UI 导出及完整分割编码 | 实际消费工具及格式要求 |
| 保存期限与恢复目标 | 备份策略和数据生命周期 | 保留期限、可接受的数据损失与恢复耗时 |
