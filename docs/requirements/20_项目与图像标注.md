# 项目与图像标注需求

图像任务的共同参与者是本地标注者；业务范围见[角色与场景](10_角色与场景.md)。字段与格式边界由[外部接口详细设计](../detailed_design/70_外部接口.md)维护。

## FR-001 项目导航与队列

**依据与确认情况**：现有文档基线；当前实现行为；[源码](../../backend/annotation_platform/server.py) `create_app`，可用验证入口为[test_platform_server.py](../../backend/tests/test_platform_server.py)。

**触发与前置条件**：工作区中已有项目（经[项目管理](40_项目管理.md)创建，或经手写注册表登记）。

列出项目、任务类型和状态；可进入详情与对应任务队列，按接口支持的分页和筛选读取数据。不存在的项目明确报错；数据集缺失和空队列不显示为可提交样本。

**验收**：[AC-001](90_验收标准.md#ac-001)。

## FR-002 图像与文本分类

**依据与确认情况**：现有文档基线；当前实现行为；[源码](../../backend/annotation_platform/classification_task.py) `ClassificationStore`，可用验证入口为[test_classification_task.py](../../backend/tests/test_classification_task.py)。

**触发与前置条件**：标注者打开配置了标签及单选或多选模式的项目。

单选只接受一个配置内标签，多选接受非空的配置内标签集合；未知或重复标签被拒绝。保存后重新读取保持已保存标签。数据源可以是图片，也可以是 UTF-8 文本文档（由 `patterns` 决定，#39）：文本按原样展示（短文本与跨段落长文档均可滚动阅读），无法按 UTF-8 解码的文档显示明确原因且不能提交结果。

**验收**：[AC-002](90_验收标准.md#ac-002)。

## FR-003 图像描述与文本自由生成

**依据与确认情况**：现有文档基线；当前实现行为；[源码](../../backend/annotation_platform/caption_task.py) `CaptionStore`，可用验证入口为[test_caption_task.py](../../backend/tests/test_caption_task.py)。

**触发与前置条件**：标注者打开图像描述（描述 / 文本生成）项目。

对图像填写自由文本，或对文本文档写出翻译、摘要等自由文本（#39，数据源规则同 FR-002）；换行和首尾空白按已有契约规范化。空白内容及超过接口长度限制（图片与文本条目各有上限）的内容被拒绝，合法 Unicode 文本能够保存并读回。

**验收**：[AC-003](90_验收标准.md#ac-003)。

## FR-004 目标检测框

**依据与确认情况**：现有文档基线；当前实现行为；[源码](../../backend/annotation_platform/detection_task.py) `DetectionStore`，可用验证入口为[test_detection_task.py](../../backend/tests/test_detection_task.py)。

**触发与前置条件**：图像已加载并获得原图尺寸，类别已配置。

支持检测框创建、选择、移动、缩放及删除；提交按原图坐标保存。未知类别、非正尺寸和越界框被拒绝；空框列表表示确认无目标。

**验收**：[AC-004](90_验收标准.md#ac-004)。

## FR-005 图像分割

**依据与确认情况**：现有文档基线；当前实现行为；[源码](../../backend/annotation_platform/segmentation_task.py) `SegmentationStore`，可用验证入口为[test_segmentation_task.py](../../backend/tests/test_segmentation_task.py)。

**触发与前置条件**：图像已加载，类别已配置。

用画笔或多边形产生同一张类别掩膜，提交完整栅格；背景与类别像素含义保持一致。错误栅格长度、非法类别像素或不一致的重复提交被拒绝。输出不能再次成为待标注源图像。

**验收**：[AC-005](90_验收标准.md#ac-005)。

## FR-006 深度图编辑

**依据与确认情况**：现有文档基线；当前实现行为；[源码](../../backend/annotation_platform/depth_task.py) `DepthStore`，可用验证入口为[test_depth_task.py](../../backend/tests/test_depth_task.py)。

**触发与前置条件**：标注者打开深度项目并加载图像。

有基线时以基线初始化，无基线时从空白缓冲区开始；画笔提高或降低灰度值，最终完整栅格单独保存，不覆盖基线。栅格长度不匹配被拒绝；基线与结果不进入源图队列。

**验收**：[AC-006](90_验收标准.md#ac-006)。

## FR-007 提交保护与重新读取

**依据与确认情况**：当前实现行为；沿用现有接口契约；[源码](../../backend/annotation_platform/task_types.py) `TaskConflictError`，可用验证入口为[test_platform_server.py](../../backend/tests/test_platform_server.py)。

**触发与前置条件**：通过统一标注入口提交已知项目中的 item。

服务端校验后才保存并返回结果与状态。同一 item 的等价结果重复提交成功，不重复追加历史；不同结果返回冲突且保留原结果。等价比较依任务类型的规范化规则，不按原始请求字节比较。该约束同样适用于 ReID 审核；ReID 判定的更正通过后续审核轮次重新作答完成，见[ReID数据闭环](30_ReID数据闭环.md)。

**验收**：[AC-007](90_验收标准.md#ac-007)。

## FR-018 文本片段标注

**依据与确认情况**：#20 的范围决定，#40 实现；[源码](../../backend/annotation_platform/text_span_task.py) `TextSpanStore`，可用验证入口为[test_text_span_task.py](../../backend/tests/test_text_span_task.py)、[text-span.test.ts](../../frontend/src/components/text-span/text-span.test.ts)。

**触发与前置条件**：标注者打开配置了标签的文本片段项目，数据源为 UTF-8 文本文档。

在文本中拖选生成片段并赋予配置内标签，可修改标签、删除片段；片段允许任意重叠、嵌套与跨段落。位置以 Unicode code point 计，必须满足 `0 <= start < end <= 文本长度`；越界、`start >= end`、非整数位置、未知标签及完全重复的片段被拒绝。空片段列表表示"没有需要标注的内容"。无法按 UTF-8 解码的文档显示原因且不能提交。提交保护同 FR-007。

**验收**：[AC-023](90_验收标准.md#ac-023)。
