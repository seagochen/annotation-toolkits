就绪
    选择左侧候选开始审核，或按 J / K 切换。

    快捷键

    1 / S同一目标（same）
    2 / D不同目标（different）
    3 / U无法判断（unclear）
    J / ↓下一个候选
    K / ↑上一个候选
    N写备注
    Z放大证据图，Esc 关闭

    标注规则

    • same 是可传递的身份边：A=B、B=C 会推出 A=C，请只在确信时使用。
    • different 是不可违反的约束边，与任何 same 链冲突都会在“冲突”页列出。
    • unclear 永远不会进入训练集，遇到模糊、遮挡、过曝时请直接选它。
    • 轨迹纯净度（track_purity）候选问的是“这条轨迹是否中途换了目标”： 选 不同目标 表示轨迹被污染，finalize 时整条轨迹会被丢弃。
    • 模型相似度只决定审核顺序，永远不是身份真值。

    在冲突链上改判

    • “冲突”页点开一条冲突链后，每条边的裁剪下方都有 相同 / 不同 / 不确定 三个按钮，直接在链上判定，不必跳回队列。
    • 该关系已有判定时，对应按钮会高亮，右侧写明这个判定的出处 （当前轮候选 / pairs.csv 的哪几行 / 哪个历史轮次）。
    • 改判已烤进 pairs.csv 的旧人判会先归档留痕 （pairs.overturned.csv + revisions.json），点击时会二次确认。
    • 抽取阶段的物理证据（共现、同一连续轨迹）网页不可推翻：新判定照样记录， 但那几行仍在 pairs.csv 里，冲突不会因此消失。
    • 每次改判后冲突会重新检测并原地刷新；整条链消失说明该冲突已解决。
