# 质量属性总体设计

目标定义归[非功能需求](../requirements/80_非功能需求.md)；这里说明措施及其限制，不报告未经测量的达标结果。

| 属性 | 需求依据 | 当前措施 | 验证与限制 |
|---|---|---|---|
| 访问边界 | NFR-001 | 明确 CORS 来源；文件解析后限制在项目根内 | [test_platform_server.py](../../backend/tests/test_platform_server.py)；CORS 不拦截直接 HTTP 客户端，也不认证用户 |
| 保存可靠性 | NFR-002、FR-007 | 任务内校验、幂等比较、进程内锁、单文件原子替换 | 各 `test_*_task.py` 与 [test_review_store.py](../../backend/tests/test_review_store.py)；多文件与多进程限制见[数据与接口](70_数据与接口.md) |
| 可观察性 | NFR-003、FR-011 | 页面状态、项目统计、动作记录与日志；重启标记中断 | [test_jobs.py](../../backend/tests/test_jobs.py)、[App.test.tsx](../../frontend/src/App.test.tsx)；没有集中指标、告警或持久任务续跑 |
| 可维护性 | NFR-004 | 通用协议、领域模块、共享画布、OpenAPI 类型 | [test_task_types.py](../../backend/tests/test_task_types.py)、[画布测试](../../frontend/src/components/image-canvas/)；前端仍需手工接入新类型 |
| 性能与容量 | NFR-005 | 分页输出、原地像素缓冲区、后端避免源图解码、重量级阶段串行 | 需按 AC-018 实测；分页不等于存储层无需扫描，整图编码与传输仍消耗内存 |
| 恢复与可用性 | 需求概述中的待确定项 | 本地文件可备份、动作历史可重载 | 未定义恢复时限或服务可用性目标；备份方案为[部署建议](90_部署与演进.md) |

## 验证移交

后端用临时文件系统夹具覆盖真实读写及错误场景；前端单测验证状态和请求，真实浏览器验证拖拽、缩放、像素读取与跨域图像。具体命令见[详细设计运维](../detailed_design/90_部署与运维.md)、[前端开发指引](../../frontend/README.md)。文档新增验收标准不自动构成测试覆盖或测试通过证据。
