# 验收标准

各场景必须在独立测试数据上验证。下列测试链接是已有验证入口，不代表覆盖该场景的每一步，也不代表本次已执行。画布指针、缩放和跨域图像需真实浏览器验证；页面测试参考 [App.test.tsx](../../frontend/src/App.test.tsx)。六种任务的完整导出和幂等检查应结合各自 `test_*_task.py`，不能只运行通用协议测试。

## AC-001

**关联需求**：[FR-001](20_项目与图像标注.md)。

**给定**：已登记的有效、空数据集、缺失数据集项目及不存在的项目 ID。

**当**：查看项目列表、详情及分页队列。

**则**：类型和入口匹配；空与缺失状态可区分；不存在项目报错；分页不超出请求范围。

**验证方式**：自动化测试与必要的浏览器演示；入口 [test_platform_server.py](../../backend/tests/test_platform_server.py)。

## AC-002

**关联需求**：[FR-002](20_项目与图像标注.md)。

**给定**：分别配置单选和多选的分类项目。

**当**：提交合法标签，再提交空集合、重复标签、未知标签及单选多标签。

**则**：合法结果读回一致；各非法结果被拒绝且不改变保存状态。

**验证方式**：自动化测试与必要的浏览器演示；入口 [test_classification_task.py](../../backend/tests/test_classification_task.py)。

## AC-003

**关联需求**：[FR-003](20_项目与图像标注.md)。

**给定**：包含中文及换行的描述输入，以及空白和超长输入。

**当**：提交并重新读取描述。

**则**：合法文本按规范化契约保存；空白和超长输入失败。

**验证方式**：自动化测试与必要的浏览器演示；入口 [test_caption_task.py](../../backend/tests/test_caption_task.py)。

## AC-004

**关联需求**：[FR-004](20_项目与图像标注.md)。

**给定**：已知尺寸和类别的图片。

**当**：在缩放视图创建、移动、缩放、删除框；分别提交合法框、空框及越界框。

**则**：交互结果映射到原图坐标；空框合法；越界和非正尺寸被拒绝。

**验证方式**：自动化测试与必要的浏览器演示；入口 [test_detection_task.py](../../backend/tests/test_detection_task.py)。

## AC-005

**关联需求**：[FR-005](20_项目与图像标注.md)。

**给定**：已知类别和尺寸的分割图片。

**当**：分别使用画笔和闭合多边形作画并保存；再提交非法像素或长度。

**则**：PNG 读回与最终类别栅格一致；非法数据不保存；结果目录不增加源图队列。

**验证方式**：自动化测试与必要的浏览器演示；入口 [test_segmentation_task.py](../../backend/tests/test_segmentation_task.py)。

## AC-006

**关联需求**：[FR-006](20_项目与图像标注.md)。

**给定**：有基线和无基线两类深度样本。

**当**：编辑并保存深度图，重新查询队列及结果。

**则**：有基线时从基线初始化，无基线时可开始编辑；结果独立保存且基线不变；错误长度被拒绝。

**验证方式**：自动化测试与必要的浏览器演示；入口 [test_depth_task.py](../../backend/tests/test_depth_task.py)。

## AC-007

**关联需求**：[FR-007](20_项目与图像标注.md)。

**给定**：每种任务已有合法提交的样本。

**当**：重复提交等价结果，再提交不同结果，刷新并重载存储。

**则**：等价结果成功且不追加重复历史；不同结果冲突；原结果保持不变。

**验证方式**：自动化测试与必要的浏览器演示；入口 [test_platform_server.py](../../backend/tests/test_platform_server.py)。

## AC-008

**关联需求**：[FR-008](30_ReID数据闭环.md)。

**给定**：可用的测试流水线和可审核候选数据。

**当**：抽取、挖掘并对候选提交人工判定；尝试提交未知候选。

**则**：可获得候选并保存人工判定；排序不替代人工标签；未知候选失败。

**验证方式**：自动化测试与必要的浏览器演示；入口 [test_extract.py](../../backend/tests/test_extract.py)。

## AC-009

**关联需求**：[FR-009](30_ReID数据闭环.md)。

**给定**：含等价与互斥矛盾、越域关系及干净对照的数据集。

**当**：检查并尝试定版，再对有效数据定版。

**则**：问题数据产生可定位报告且不被视为有效定版；对照数据生成可用产物。

**验证方式**：自动化测试与必要的浏览器演示；入口 [test_conflicts.py](../../backend/tests/test_conflicts.py)。

## AC-010

**关联需求**：[FR-010](30_ReID数据闭环.md)。

**给定**：有效定版数据与测试训练器，以及未解决标签、矛盾或缺少训练器的样本。

**当**：执行交接校验与测试训练调用。

**则**：有效数据引用正确且记录交接；无效前置条件明确失败；不以模型精度作为此次验收条件。

**验证方式**：自动化测试与必要的浏览器演示；入口 [test_handoff.py](../../backend/tests/test_handoff.py)。

## AC-011

**关联需求**：[FR-011](30_ReID数据闭环.md)。

**给定**：两个 ReID 项目和可控制结束时间的测试动作。

**当**：启动动作、在执行中启动另一个动作、查询记录并模拟服务重启。

**则**：同进程新动作得到忙碌反馈；状态与日志可查；未完成记录重载后失败，不自动续跑。

**验证方式**：自动化测试与必要的浏览器演示；入口 [test_jobs.py](../../backend/tests/test_jobs.py)。

## AC-012

**关联需求**：[FR-012](70_数据与外部交互.md)。

**给定**：各任务已保存结果及图片、基线、栅格文件。

**当**：通过 Python 导出各自支持的格式并读取关联产物，再请求不支持的格式。

**则**：支持的产物可解析且引用可解析；分割按掩膜引用契约核验；不支持的格式失败。

**验证方式**：自动化测试与必要的浏览器演示；入口 [test_task_types.py](../../backend/tests/test_task_types.py)。

## AC-013

**关联需求**：[FR-013](70_数据与外部交互.md)。

**给定**：后端不可达、缺失文件及会失败的外部阶段。

**当**：请求页面数据、读取文件或启动外部阶段。

**则**：页面/API/动作记录分别呈现失败，不能呈现操作成功；根目录外文件不返回内容。

**验证方式**：自动化测试与必要的浏览器演示；入口 [test_platform_server.py](../../backend/tests/test_platform_server.py)。

## AC-014

**关联需求**：[NFR-001](80_非功能需求.md)。

**给定**：允许与不允许的浏览器来源，以及越界路径和指向根外的符号链接。

**当**：执行跨域预检和文件读取。

**则**：仅配置来源获得 CORS 许可；越界文件不可读取；核验无认证的已知边界。

**验证方式**：自动化测试与必要的浏览器演示；入口 [test_platform_server.py](../../backend/tests/test_platform_server.py)。

## AC-015

**关联需求**：[NFR-002](80_非功能需求.md)。

**给定**：已有结果文件和可注入的单文件写入/替换失败。

**当**：提交非法结果、冲突结果，或在单文件落盘中注入异常。

**则**：旧文件仍可解析且内容未被非法结果覆盖；不将该结论推广为 PNG 与索引的事务保证。

**验证方式**：自动化测试与必要的浏览器演示；入口 [test_segmentation_task.py](../../backend/tests/test_segmentation_task.py)。

## AC-016

**关联需求**：[NFR-003](80_非功能需求.md)。

**给定**：加载、空队列、网络失败、提交失败及中断动作状态。

**当**：观察页面并重新读取动作历史。

**则**：状态各自可辨识；错误不被当成提交成功；中断原因可查询。

**验证方式**：自动化测试与必要的浏览器演示；入口 [test_jobs.py](../../backend/tests/test_jobs.py)。

## AC-017

**关联需求**：[NFR-004](80_非功能需求.md)。

**给定**：实现最小通用协议的测试任务及普通视觉任务环境。

**当**：注册任务并通过统一 API 读队列、提交；核对依赖和画布复用。

**则**：平台无需解释任务专属字段；普通视觉路径不加载可选模型包；页面路由仍需显式接入。

**验证方式**：自动化测试与必要的浏览器演示；入口 [test_task_types.py](../../backend/tests/test_task_types.py)。

## AC-018

**关联需求**：[NFR-005](80_非功能需求.md)。

**给定**：代表性图片、项目规模、浏览器和主机信息。

**当**：测量队列、整图提交的耗时及浏览器/后端内存。

**则**：记录条件与测量结果；目标阈值未确认前，仅形成基线，不判定性能验收通过。

**验证方式**：实测记录；待业务确认指标后补充阈值。
