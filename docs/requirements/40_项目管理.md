# 项目管理需求

项目在浏览器中创建、导入数据、修改属性和删除，平台把结果写入工作区；参与者是承担数据集准备职责的本地使用者，见[角色与场景](10_角色与场景.md)。端点、错误码与字段由[外部接口详细设计](../detailed_design/70_外部接口.md)"项目管理"一节维护，工作区布局见[配置参考](../detailed_design/80_配置参考.md) §1。平台无账户认证，下列安全约束承担的是"不把 HTTP 写入能力扩大为服务器文件读写或代码执行"的边界，不是用户权限隔离，见 [NFR-001](80_非功能需求.md)。

## FR-014 新建项目

**依据与确认情况**：当前实现行为；[源码](../../backend/annotation_platform/workspace.py) `Workspace`、[project_forms.py](../../backend/annotation_platform/project_forms.py) 的任务类型表单定义，可用验证入口为 [test_workspace.py](../../backend/tests/test_workspace.py) 与 [App.test.tsx](../../frontend/src/App.test.tsx)。

**触发与前置条件**：使用者在浏览器中选择"新建项目"。

选择任务类型后按该类型的属性表单填写名称与属性，创建成功后进入项目概览。项目 ID 由名称生成且不重复，名称不含可用字符时以任务类型为前缀。名称为空或过长、未知任务类型、未知或类型不符的属性、缺失必填属性、只能在服务器上修改的属性被拒绝；任务模块拒绝生成的配置时同样失败。任何失败都不留下半成品目录，已有项目列表保持可读。

**验收**：[AC-019](90_验收标准.md#ac-019)。

## FR-015 导入数据

**依据与确认情况**：当前实现行为；[源码](../../backend/annotation_platform/workspace.py) `Workspace` 的上传、zip 导入与目录关联，可用验证入口为 [test_workspace.py](../../backend/tests/test_workspace.py)。

**触发与前置条件**：项目已创建；图像任务项目处于托管数据目录模式时可上传，任何项目可关联服务器目录。

数据来源二选一：

- **上传**：逐张上传图片、上传文件夹或 zip，保存到项目的托管数据目录并保留相对路径。只接受 JPEG/PNG/WebP（扩展名与文件头均需符合），扩展名统一为小写；zip 中的非图片、隐藏路径、越界路径和损坏条目跳过并计数，结果报告导入数与跳过数。路径不能指向平台自身的目录（如 `.annotations`）。ReID 项目不接受上传，数据由抽取动作生成或关联已有目录。
- **关联服务器目录**：把已有目录作为项目数据集根目录。只允许工作区内或部署者以 `ANNOTATION_IMPORT_ROOTS` 显式放行的目录；不允许关联其他项目已使用的目录；托管目录已有数据时不能切换到关联模式。

导入后队列反映新数据；导入失败不改变已有数据与配置。

**验收**：[AC-020](90_验收标准.md#ac-020)。

## FR-016 修改项目属性

**依据与确认情况**：当前实现行为；[源码](../../backend/annotation_platform/workspace.py) `Workspace`、[ListEditor.tsx](../../frontend/src/components/settings/ListEditor.tsx) `ListEditor`，可用验证入口为 [test_workspace.py](../../backend/tests/test_workspace.py) 与 [App.test.tsx](../../frontend/src/App.test.tsx)。

**触发与前置条件**：使用者打开项目属性页。

可以通过表单修改名称与属性，或直接编辑完整配置文本；两种方式写入前都由任务模块校验，校验失败不改变原配置。类别/标签列表逐项编辑，支持追加、改名、删除和调整顺序。

项目**已有标注**后，类别/标签只能在末尾追加，已有条目不能修改、删除或移动，单选/多选等决定已有数据含义的属性不能修改——类别顺序决定分割像素值与 COCO 类别编号，改变它会改变已有数据的解释。会被平台当作程序执行的配置项（如 ReID 训练器/评估器及其解释器）、决定输出位置的配置项，以及数据集位置，均不能经浏览器修改；模型/权重路径不能指向经 HTTP 可写入的项目目录。

**验收**：[AC-021](90_验收标准.md#ac-021)。

## FR-017 删除项目

**依据与确认情况**：当前实现行为；[源码](../../backend/annotation_platform/workspace.py) `Workspace`，可用验证入口为 [test_workspace.py](../../backend/tests/test_workspace.py) 与 [App.test.tsx](../../frontend/src/App.test.tsx)。

**触发与前置条件**：使用者在属性页输入项目名称确认删除。

删除后项目从列表中消失，平台托管的项目目录（含上传的图片与标注结果）一并删除。关联的服务器目录及其中的标注结果从不删除；手写注册表登记的项目只取消登记，不删除任何文件。删除没有回收站或撤销，备份建议见[部署与演进](../overall_design/90_部署与演进.md)。

**验收**：[AC-022](90_验收标准.md#ac-022)。
