# 术语表

| 术语 | 说明 |
|---|---|
| 任务类型（task type） | 一种标注工作流的实现（`reid`/`classification`/`captioning`/`detection`/`segmentation`/`depth`），必须实现 `TaskTypeModule` 协议。见 [`task_types.py`](../../backend/annotation_platform/task_types.py) `TaskTypeModule`。 |
| 项目（project） | `projects.yaml` 里的一条注册条目：一个 `id` + 一种 `task_type` + 一份该任务类型自己的配置文件。见 [`80_配置参考.md`](80_配置参考.md) §1。 |
| `TaskProject` | 平台层与任务类型模块之间传递的任务无关载体：`config_path`、`root`、模块自己的 `value`。平台层和 HTTP 层只认这三个字段，不解释 `value` 内部结构。见 [`task_types.py`](../../backend/annotation_platform/task_types.py) `TaskProject`。 |
| item / item_id | 队列里的一个待标注单元（通常是一张图或一个 ReID 候选对）。`item_id` 由该 item 的稳定标识（如数据集内相对路径）做 sha256 派生，跨进程重启保持不变。见各 `*_task.py` 的 `images()`。 |
| 队列（queue） | `TaskTypeModule.queue()` 按分页与过滤条件返回的待处理/已处理 item 列表。过滤语义因任务而异（如 `status=pending`），但方法签名统一。 |
| 提交（submission） | `TaskTypeModule.submit()` 接收的一次标注结果：`item_id` + 任务自定义的 `result` 字典。平台层不解释 `result` 内部字段。 |
| 幂等提交 / 冲突 | 同一 `item_id` 重复提交相同结果视为成功（幂等）；提交不同结果一律拒绝为 `TaskConflictError`（HTTP 409），不会覆盖已保存结果——这是六个内置任务类型共有的约定，不是协议强制的，但全部遵循。 |
| 原子写入 | 写临时文件 + `fsync` + `rename` 落地，失败时不留半成品文件。见 [`local_files.py`](../../backend/annotation_platform/local_files.py) `atomic_write_json`/`atomic_write_csv`/`atomic_write_bytes`。 |
| 整图栅格提交 | 分割/深度任务的提交模型：无论前端用画笔还是多边形作画，提交给后端的永远是**整张图**的像素栅格（base64），不是增量笔画或矢量顶点。见 [`20_标注平台后端.md`](20_标注平台后端.md) §5。 |
| 灰度 PNG 编码器 | [`imaging.py`](../../backend/annotation_platform/imaging.py) 的 `encode_gray8_png`：纯标准库实现的单色 8-bit PNG 编码器，只编码不解码。分割掩膜与深度图落盘的唯一途径。 |
| 基线深度图（baseline depth map） | 深度任务里标注者编辑前已存在的参考灰度深度图，由项目配置的 `depth_maps` 目录提供；编辑结果落在独立的 `annotations` 目录，不覆盖基线。见 [`80_配置参考.md`](80_配置参考.md) §3。 |
| COCO 兼容导出 | 检测/分割的 `format=coco` 导出：字段形状参照 COCO，但分割的 `segmentation` 字段是掩膜 PNG 文件路径引用，不是完整的 RLE/polygon 编码。见 [`70_外部接口.md`](70_外部接口.md)。 |
| 候选（candidate） | ReID 任务里一对需要人工判定"是否同一人"的裁剪图。见 [`30_ReID流水线.md`](30_ReID流水线.md) §4。 |
| 逻辑冲突（logic conflict） | ReID 身份关系图上不可能同时成立的一组人工判定（如 A=B、B=C、A≠C）。见 [`conflicts.py`](../../backend/reid_annotation_tool/conflicts.py)。 |
| 数据定版（finalize） | 把逻辑冲突清零后的 ReID 数据集标记为可训练版本的动作。见 [`30_ReID流水线.md`](30_ReID流水线.md) §4。 |
| 训练交接（handoff） | 把定版数据集的路径与统计信息交给外部训练脚本，本工具不训练模型。见 [`handoff.py`](../../backend/reid_annotation_tool/handoff.py)。 |
| Action / Job | ReID 任务类型独有的后台异步操作（`extract`/`mine`/`check`/`finalize`/`purge-domain`/`train`），通过 `TaskActionModule` 协议暴露，用轮询查看进度。见 [`jobs.py`](../../backend/reid_annotation_tool/jobs.py)。 |
| 图像画布图元（image-canvas primitives） | 前端 `components/image-canvas/` 下与具体任务无关的共享模块：视口几何（`geometry.ts`）、快捷键（`shortcuts.ts`）、检测框（`box-tool.ts`）、多边形（`polygon-tool.ts`）、像素栅格（`raster-buffer.ts`）。见 [`40_React前端.md`](40_React前端.md) §5。 |
